Privacy Policy

Effective date: September 13, 2026

Purpose

SDA Church Calendar Integration is a private, locally run utility that extracts food-drive information from publicly available church bulletins and creates corresponding events in the user's Google Calendar.

Google user data

The application requests Google Calendar access solely to search for duplicate food-drive events and to create matching calendar events. It does not use Google user data for advertising, profiling, or any unrelated purpose.

Storage and sharing

OAuth credentials and tokens are stored locally on the user's computer. The application does not operate a remote database or server for user data. Google user data is not sold, shared with third parties, or transferred for advertising.

Retention and deletion

The application retains only the local OAuth token needed to access the authorized calendar. The user may delete the local token file at any time and may revoke the application's access through Google Account security settings.

Security

Access is limited to the Google account explicitly authorized by the user. Local credential and token files are excluded from source control.
